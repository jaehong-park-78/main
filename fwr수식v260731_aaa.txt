# ✦ FWR  — 수식 완결 명세 ✦

---

## 시스템 정의

```
X(n) = [T(n), W(n)]ᵀ
T(n) ∈ [0, ∞), W(n) ∈ [0, 1]
F(n) ∈ [0, 1], C(n) ∈ [-1, 1], W*_k ∈ [0, 1]
α > 0, η ∈ (0, 1], γ ∈ (0, 1], β ∈ [0, 1]
```

---

## 출력 방정식

```
E(n) = min(F(n), W(n)) · C(n) · η · [1 + T(n)/(1 + αT(n))]
```

---

## 위기 판정

```
crisis(n) :≡ E(n) ≤ γ · T(n)
```

---

## 상태 전이 (n → n+1)

### 위기 시:
```
T(n+1) = β · T(n)
W(n+1) = W*_k
```

### 정상 시:
```
T(n+1) = T(n) + |E(n)| − γ · T(n)
W(n+1) = W(n)
```

---

## 파생 개념

```
Pivot Sequence = { n | crisis(n) }
```

---

## 안정화 조건

```
Stabilization ⇔ ∃K, ∀n ≥ K, ¬crisis(n)
```

---

## 유계성

```
lim_{n→∞} T(n) ≤ (1 + 1/α) / γ
```

---

## 전체 공리 블록

```
[1] X(n) = [T(n), W(n)]ᵀ, T∈[0,∞), W∈[0,1]

[2] E(n) = min(F(n), W(n)) · C(n) · η · [1 + T(n)/(1+αT(n))]

[3] crisis(n) :≡ E(n) ≤ γ·T(n)

[4] crisis(n) = True:
        T(n+1) = β·T(n),  W(n+1) = W*_k
    crisis(n) = False:
        T(n+1) = T(n) + |E(n)| − γ·T(n),  W(n+1) = W(n)

[5] { n | crisis(n) } (pivot sequence)

[6] ∃K, ∀n≥K, ¬crisis(n) (stabilization)

[7] lim T(n) ≤ (1 + 1/α)/γ (boundedness)
```
