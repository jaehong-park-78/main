## 3. FWR-SAT Framework
### 3.1 Definitions
- SAT: CNF \(\phi = \bigwedge C_j\) (\(m\) clauses, n vars, satisfiable).
- Energy: \(E(A) = \sum \mathbb{I}[C_j=\bot]\).
- FWR: Flow \(A(0)\sim\mathcal{U}\); Wave \(W_k = a_k e^{i\theta_k}\); Resonance \(R = \sum \frac{F W_k}{1-i\delta\omega_k}\) (\(\delta\omega_k < \varepsilon\)).
- DE: \(\dot{E} = -\gamma |R|^2 E\); Cooling \(T(t) = T_0 / \log(t + t_e)\).

### 3.2 Algorithm
```
A ← random(); E ← eval(A); T ← T_0
for t=1 to max_iter:
    flip random k; ΔE ← eval(flip(A,k)) - E
    if rand() < min(1, exp(-ΔE/T)): A←flip(A,k); E←ΔE
    T ← T_0 / log(t + t_e)
    if E=0: return A
```
