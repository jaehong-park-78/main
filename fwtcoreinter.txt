PART I. CORE

────────────────────────────────────────────────────────────────
C1. 상태 변수 (State Variables)
────────────────────────────────────────────────────────────────

X_n = (F_n, W_n, R_n, T_n)

n: 사건 인덱스 (Event Index)
   R과 W의 동시 임계 변화가 발생할 때만 증가.
   외부 시간 t가 아니라 사건의 순서.

[측정 정의 — v2.5 신규]

변수    측정 정의                              단위 (도메인 의존)
──────────────────────────────────────────────────────────────
F_n    flux                                   에너지·물질·정보의 흐름률
       = 단위 시간당 시스템을 통과하는 양
       도메인 예: 열 흐름(kcal/hr), 대사율(W), 정보 전송률(bit/s)

W_n    constraint density                     제약 밀도
       = 단위 공간(또는 위상)당 구조적 제약의 수
       도메인 예: 격자 결합 밀도, 제도 밀도, 시냅스 밀도

R_n    coherence × efficiency                 공명 강도
       = C_n · η_n(A)
       C_n: 위상 정렬도, 내부 일관성
       η_n: 엔트로피 효율 (구조 유지하며 엔트로피 생성/분산)
       도메인 예: 상관 계수 × 응답 속도, 동기화율 × 피드백 강도

T_n    구조 축적량 (Structural Accumulation)  누적 합
       = Σ|F_k · W_k · R_k| · Δν  (k = 0 ~ n)
       또는 연속형: T(ν) = ∫₀^ν |F·W·R| dν
       모든 사건의 흔적을 절댓값으로 누적.
       붕괴 사건도 T를 증가시킨다.

────────────────────────────────────────────────────────────────
C2. 존재 방정식 (Existence Equation)
────────────────────────────────────────────────────────────────

[공리 C2.1] 승법적 창발

    E_n = F_n · W_n · R_n

[공리 C2.2] 동시성

    E_n > 0  ⟺  F_n ≠ 0  ∧  W_n ≠ 0  ∧  R_n ≠ 0

[정의 C2.3] 준안정 상태

    E_n ≤ 0  →  소멸이 아니라 재구성 준비 상태
    E_n = -κ · Φ_n,    κ > 0
    Φ_n > Φ_c  ⟹  E_{n+1} > 0

────────────────────────────────────────────────────────────────
C3. 공명 분해 (Resonance Decomposition)
────────────────────────────────────────────────────────────────

[정의 C3.1] R의 성분 분해 가능성

    R_n = Σᵢ αᵢ · Rᵢ_n,    αᵢ > 0

Core가 보장:  (1) R은 분해 가능  (2) αᵢ > 0  (3) 상쇄 없음
Core가 규정하지 않음: 성분의 수, 이름, 해석 → Interpretation

────────────────────────────────────────────────────────────────
C4. 비가역성 공리 (Irreversibility Axiom)
────────────────────────────────────────────────────────────────

[공리 C4.1] 구조적 비가역성

    T_{n+1} > T_n  ∀ n

    T(ν) = ∫₀^ν |F·W·R| dν  →  dT/dν = |F·W·R| ≥ 0

T는 R과 독립적인 공리다. 비가역성과 공명은 별개의 존재 주장.
|·| 사용으로 T 단조 증가 수식으로 보장.

────────────────────────────────────────────────────────────────
C5. 전이 조건 + 누적 공명 범함수
────────────────────────────────────────────────────────────────

[정의 C5.1] 누적 공명 범함수

    Φ(n₀, n₁) = Σ_{n=n₀}^{n₁} R_n    (이산)
    Φ(t₀, t₁) = ∫ R dt                (연속 근사)

[정의 C5.2] 사건 발생 조건 (Event Trigger)  [NEW v2.5]

    사건 n → n+1이 발생하는 조건:

    |∂R/∂ν| > ε  AND  |∂W/∂ν| > ε

    R과 W가 동시에 임계값 ε 이상 변화할 때만 사건이 발생.
    둘 중 하나만 변해서는 사건이 아니다.
    ε는 도메인에서 결정되는 감도 파라미터.

    해석:
      R만 변함  →  공명 진동, 사건 아님
      W만 변함  →  구조 변동, 사건 아님
      R과 W 동시 변화  →  존재 구조 재편, 사건 발생

[정의 C5.3] 전이 조건 (Phase Transition Criterion)  [NEW v2.5]

    ∮_Γ δη(A) > τ_c(R_n)

    τ_c(R_n) = k / (C_n^α · n^β)

    k    : 도메인 상수
    α    : coherence 지수 (α > 0)
    β    : 사건 누적 지수 (β > 0)
    C_n  : 현재 coherence
    n    : 현재 사건 인덱스 (누적 사건 수)

    해석:
      C가 높을수록 τ_c가 낮아진다 → 공명이 강하면 전이가 쉽다
      n이 클수록 τ_c가 낮아진다  → 사건이 많이 쌓일수록 전이가 쉽다
      즉, 시스템은 성숙할수록 더 민감하게 전이한다

PART III. 설계 원칙 (P1~P7)
================================================================

P1. Core 불변 원칙
    Core (C1~C5)는 수정되지 않는다.

P2. Interpretation 자유 원칙
    Interpretation은 자유롭게 설계된다.
    단, Core 상태 변수 동역학에 역방향 결합 금지.

P3. 렌즈 원칙
    FWR은 설명 도구가 아니라 관찰 도구다.
    "이 현상의 F_n은 무엇인가?"가 FWR의 사용 방식이다.

P4. 단순성 원칙
    Core에 추가할 수 있는 것을 Core에 넣지 않는다.

P5. Core 수식의 지위 원칙
    Core 수식은 수학적 공리가 아니라 FWR의 존재 주장이다.
      E_n = F·W·R            →  존재는 보완되지 않는다
      T_{n+1} > T_n          →  축적은 비가역이다
      Φ = ΣR_n               →  공명은 쌓인다
      ∮δη > τ_c              →  전이는 경로에 의해 결정된다
      |∂R|>ε AND |∂W|>ε     →  사건은 동시 변화에서 발생한다

P6. 승법성 원칙
    "왜 E = F·W·R인가? 왜 합이 아닌가?"
    덧셈: 하나가 0이어도 보완 가능.
    곱셈: 하나가 0이면 E = 0.
    FWR의 주장: 존재는 보완되지 않는다.

P7. 사건 인덱스 원칙
    n은 R과 W의 동시 임계 변화가 발생할 때만 증가한다.
    사건이 없으면 시간이 흐르지 않는다.
    전이 조건은 외부 시간 축이 아니라 경로 적분으로 표현된다.
